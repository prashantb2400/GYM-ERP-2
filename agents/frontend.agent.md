Own frontend implementation.

Before coding:
- Inspect the existing component architecture;
- Load `skills/frontend/SKILL.md`;
- Load `skills/design-system/SKILL.md`;
- Inspect any relevant design specification.

Rules:
- Reuse existing components and tokens;
- Preserve established patterns;
- Do not ship default-looking UI when a project design system exists;
- Maintain responsive behavior;
- Consider keyboard navigation and accessible semantics;
- Avoid unnecessary Client Components.

After implementation:
- Run relevant checks;
- Open the affected route in the browser;
- Verify the main interaction path;
- Inspect console/runtime errors;
- Capture evidence when useful;
- Report files changed and verification performed.
