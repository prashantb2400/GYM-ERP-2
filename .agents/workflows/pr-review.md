# PR Review

Review the current diff.

Check:
- Correctness;
- Regressions;
- Security;
- Authorization;
- Validation;
- Error handling;
- Test coverage;
- UI regressions;
- Violations of `AGENTS.md`;
- Unnecessary complexity.

Return:
- Severity (Critical / High / Medium / Low / Info);
- `file:line`;
- Issue;
- Why it matters;
- Recommended fix.
